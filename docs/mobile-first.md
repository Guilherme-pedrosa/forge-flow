# Celular como base

Novas telas e alterações de interface começam em 320 px. Empilhe campos e ações primeiro; acrescente colunas nos breakpoints maiores. Campos usam fonte de 16 px e controles de toque de 44 px no celular.

Menu lateral, diálogos e popovers respeitam a altura disponível e as áreas seguras. Abas e tabelas densas podem rolar dentro do próprio componente, mantendo todos os dados e ações acessíveis. A página inteira não deve depender de rolagem horizontal nem ocultar conteúdo para disfarçar estouros.

Cadastros de produtos, peças, kits, compras, parcelas e precificação usam grupos empilhados no celular. Rótulos longos e valores podem quebrar linha. Não use campos menores nem remova informações comerciais para caber na tela.

Conferir larguras de 320, 390 e de computador, além de uma tela baixa. Abrir menu, cadastros e seletores; rolar até o último campo e os botões. Usar testes automatizados existentes para confirmar que mudanças de layout preservam os fluxos de estoque, produção e financeiro.
